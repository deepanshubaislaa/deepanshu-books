# Deepanshu Baisla — Books

A small, static author website containing two original short philosophical books.

## Contents
- `index.html` — homepage for GitHub Pages
- `books/*.pdf` — reading editions
- `books/*.md` — editable source manuscripts
- `assets/*.png` — cover artwork

## Publish with GitHub Pages
1. Create a new public GitHub repository, for example `deepanshu-books`.
2. Upload the contents of this folder (not the enclosing ZIP) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. After GitHub finishes publishing, your site will appear at `https://YOUR-USERNAME.github.io/deepanshu-books/`.

## Before publishing
Read both manuscripts and make any personal edits you want. These are original AI-assisted drafts prepared for Deepanshu Baisla; review the wording and ensure it reflects your own voice before presenting them publicly.
